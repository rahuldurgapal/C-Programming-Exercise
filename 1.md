1. Voting Eligibility Checker
Take age as input from user. Check if the person is eligible to vote (age >= 18). Print appropriate message.

2. Odd or Even Number Checker
Take an integer input from the user and determine whether it is odd or even using if-else.

3. Electricity Bill Calculator
Take total electricity units consumed as input. Calculate bill using:

First 100 units: ₹1/unit

Next 200 units: ₹2/unit

Above 300 units: ₹3/unit
Use if-else if ladder.

4. Number Sign Checker
Take an integer input and check whether the number is positive, negative, or zero using if-else-if.

5. Grade Calculator
Input student’s marks (0 to 100). Use if-else to print grade as per:

90–100: A

70–89: B

50–69: C

35–49: D

< 35: Fail

6. Minimum of Two Numbers Using Conditional Operator
Take two integers and find the smaller one using conditional operator (?:).

7. Traffic Signal Meaning (Switch Case)
Take a character input:

'R' → Red

'Y' → Yellow

'G' → Green
Use switch-case to print what action the signal indicates.

8. Leap Year Checker
Take a year as input. Use nested if to check if it’s a leap year:

Divisible by 400 → leap

Divisible by 100 → not leap

Divisible by 4 → leap

Else → not leap

9. Simple Calculator (Switch Case)
Input two numbers and an operator (+, -, *, /). Use switch-case to perform the operation.

10. Discount Calculator
Take amount as input. Apply discount:

₹10000 → 20%

₹5000–10000 → 10%

< ₹5000 → No discount

11. Temperature Status
Take temperature in Celsius. Classify it as:

= 40: "Very Hot"

30–39: "Hot"

20–29: "Warm"

10–19: "Cool"

<10: "Very Cold"

Use if-else-if.

12. Check if Number is Multiple of 3 and 5
Take integer input. Print message if the number is divisible by both 3 and 5.

13. ATM Transaction
Take account balance and withdrawal amount as input. Check if withdrawal is possible:

Must be in multiples of 100

Must not exceed balance
Print appropriate message.

14. Marks Pass/Fail Status Using Conditional Operator
Input marks out of 100. Print “Pass” if marks >= 35, otherwise “Fail” using conditional operator.

15. Menu-Based Food Order (Switch Case)
Show a menu:

Pizza ₹150

Burger ₹100

Sandwich ₹80

Exit
Take user choice using switch and print selected item and price.
